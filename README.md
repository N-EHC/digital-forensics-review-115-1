## 使用

以瀏覽器開啟 index.html，或前往上方 GitHub Pages 網址。閱讀進度只儲存在使用者自己的瀏覽器；網站沒有伺服器資料收集與第三方追蹤。

notes.md 是同內容文字筆記。來源索引保留原檔名與頁碼，未公開原始課堂簡報或本機路徑。

期中考範圍請以教師公告為準；案例、法律及舊版技術限制依教材整理，適用限制已標示。
